# Серверная часть веб-платформы автошколы (Backend API)

Масштабируемый и безопасный REST API сервер, обеспечивающий бизнес-логику, разграничение прав доступа и управление реляционной базой данных информационной системы автошколы ГАПОУ СО «БТМСХ».

🔗 **Репозиторий фронтенда:** [Rostislav-565/auto-school-crm](https://github.com/Rostislav-565/auto-school-crm)

## 🛠 Стек технологий
* **Фреймворк:** NestJS (Node.js) с модульной архитектурой (Modules, Controllers, Services)
* **Язык:** TypeScript
* **База данных:** PostgreSQL
* **ORM:** Prisma Client (типизированные запросы и миграции)
* **Безопасность:** JWT (JSON Web Tokens), Passport.js, bcrypt

## 🔒 Безопасность и Архитектура базы данных
* **RBAC (Role-Based Access Control):** Защита эндпоинтов сервера на основе ролей пользователей с помощью перехватчиков `NestJS Guards`.
* **Защита данных:** Хэширование и верификация паролей пользователей с использованием алгоритма `bcrypt`.
* **Целостность данных:** Реляционная схема БД состоит из 9 таблиц, приведенных к 3-й нормальной форме (3NF). Все транзакции изменения связанных данных выполняются атомарно через `prisma.$transaction`.
* **Алгоритм защиты от коллизий:** При записи на вождение сервер производит предикативную проверку доступности конкретного инструктора и автомобиля, исключая накладки по времени.
